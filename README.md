Game Jam 1 was a two-week game jam where each participant had to make either a racing game or endless runner like game with a pickle theme. 
I decided to make a game where the player is a pickle that needs to outrun a hamburger to save his life. 
I imported royalty free sounds and a free hamburger asset, all other assets I made within Unity and Blender.
